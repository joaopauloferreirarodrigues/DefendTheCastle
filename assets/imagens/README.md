# Imagens

Pasta destinada a sprites, fundos, icones e outros elementos visuais.

## Conteudo atual

- `arqueiro.png`: sprite do arqueiro (jogador), com fundo transparente.
- `esqueleto.png`: sprite do esqueleto (inimigo), com fundo transparente.
- `morcego.png`: sprite do morcego (inimigo), com fundo transparente.
- `orc.png`: sprite do orc (inimigo), com fundo transparente.
- `flecha.png`: sprite da flecha disparada pelo arqueiro, com fundo transparente.
- `spritesheet.bmp`: spritesheet base do template (de onde o arqueiro e o morcego foram recortados).

## Recomendações

- Separe imagens por tema quando o projeto crescer.
- Mantenha dimensoes e padroes consistentes para facilitar colisao e animacao.
- Prefira formatos com transparencia quando necessario (ex.: `.png`).
